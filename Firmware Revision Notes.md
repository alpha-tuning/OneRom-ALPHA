## ALPHA OneROM AutoSave Beta Firmware v1.01

**Status:** Beta  
**Tested With:** Windows 11, Honda Tuning Suite (HTS)

### Features
- Ostrich-type compatibility
- Read support
- Write support
- Live-update support

### Changes
- Added automatic save-to-flash behavior
- 3 seconds after the last update is made, the current map is automatically written to persistent memory (flash)

### Bugs
- None reported at this time

### Future Updates
- Datalogging support
